# LCM V5 七项认知专项测试报告

日期：2026-09-08

基线：V3 answer-only 因果学生，800 步，最终推理不加载 Qwen。

## 1. 认知状态因果干预

| 条件 | 序列 CE | 首 token 准确率 |
|---|---:|---:|
| 正确认知状态 | 0.0323 | 100% |
| 全零认知状态 | 3.1031 | 0% |
| 样本间错配状态 | 4.5426 | 0% |

结论：主动输出强依赖认知状态；状态不是无效前缀。错配比归零破坏更大，说明错误认知会定向干扰回答。

## 2. 主动/被动一致性

当前 V3 检查点没有保存原设计中的 `W_out`，所以不能伪称完成了真正的被动文本通道测试。替代测试是在认知状态上训练线性读取探针：留出样本的首答案类别准确率为 100%，并与主动头首 token 一致。

这证明状态可线性读取，但由于留出集包含同一答案的改写，结果只适用于小域，不代表开放域诚实性。

## 3. 反事实

- 零样本基线：0/4。
- 六条反事实专项训练后，四条未见改写：3/4。

模型能学习否定前提带来的结果翻转，但植物样本仍回落到原始“缺水萎蔫”记忆，说明强旧记忆会压过反事实条件。

## 4. 直接多步因果

用三条两跳因果链训练，再测试三条未见改写：3/3。模型能够在已见过链结构后保持两步结果与语言改写稳定。

## 5. 记忆更新

将“狗怎样叫”的答案人为改为原手机关机答案：

- 带旧记忆回放训练 200 步：新记忆 0/1，其余旧记忆 19/19。
- 无回放强制训练 120 步：新记忆 1/1，其余旧记忆仅 1/19 保留。

模型表现出明显稳定—可塑性冲突：回放使旧记忆过强而无法更新；无回放则产生灾难性遗忘和全局答案坍缩。

## 6. 组合泛化

只训练 `A→B` 和 `B→C`，不训练 `A→C`，测试三条组合链：1/3。成功项是“雨→湿地→结冰”；手机恢复供电和燃烧升温均停留在第一跳或旧答案。

因此当前模型有一次组合成功，但没有稳定的关系组合能力。

## 7. 状态可读性

线性探针在小域留出改写上为 100%；结合归零/错配干预，可确认认知状态同时具备可读取信息和对主动输出的因果控制力。下一版必须恢复独立被动读出头，并在训练时限制它只能读取、不能反向改变认知状态。

## 总结

| 项目 | 结果 |
|---|---|
| 状态干预 | 通过，效应强 |
| 小域状态可读性 | 通过，但测试偏易 |
| 主动/被动真实一致性 | 未完成，缺少被动头 |
| 反事实专项泛化 | 3/4 |
| 直接多步专项泛化 | 3/3 |
| 组合泛化 | 1/3 |
| 带回放记忆更新 | 更新失败，保留 19/19 |
| 无回放记忆更新 | 更新成功，保留 1/19 |

最重要的新证据是：改变认知状态会系统性改变主动输出，说明因果性确实经过主模型状态；当前主要问题已从“有没有因果作用”转为“如何获得反事实组合能力，以及如何解决稳定—可塑性冲突”。
