# LCM 双通道认知与因果对话实验报告 V2.1

> 状态：实验性验证报告
> 日期：2026-09-08
> 项目：Lattice Cognitive Model（LCM）
> 核心问题：认知状态能否通过梯度塑造独立主动通道，并在剥离 Qwen 后保留连续、具有因果方向的语言输出

---

## 摘要

本轮实验围绕 LCM 的双通道设计展开。主动通道负责形成可供外部交流的连续语言；被动通道的目标是诚实而实用地暴露当前内部状态，但模型本身不应被假定知道该状态正在被读取。Qwen2.5-0.5B-Instruct 仅作为训练期语言教师或初始化来源，不属于最终推理结构。实验的关键判据不是“接入 Qwen 后能否说话”，而是移除 Qwen 后，LCM 自身的认知编码器、认知格和主动生成头能否继续生成与输入相关的语言。

在纠正训练数据路径、改为 answer-only 解码、加入认知残差、持续状态注入和 EOS 监督后，64 维小域学生在 20 个基础因果问题及 20 个同义改写上完成拟合；第三套未见改写中，约 11/20 保持正确主题或因果方向。进一步的认知状态干预显示：使用正确状态时序列交叉熵为 0.0323、首 token 准确率为 100%；状态归零后交叉熵升至 3.1031，状态在样本间错配后升至 4.5426，两者首 token 准确率均降为 0%。这一结果表明，主动输出确实受到主模型认知状态的因果控制，而不只是生成头独立记忆答案。

专项训练后，反事实未见改写达到 3/4，直接训练过结构的两跳因果达到 3/3；但只提供 `A→B` 与 `B→C`、要求模型自行推出 `A→C` 时仅达到 1/3。记忆更新实验揭示明显的稳定—可塑性冲突：带旧记忆回放时旧知识保留 19/19，但目标新记忆无法写入；无回放强制更新时新记忆写入成功，但旧知识仅保留 1/19。开放域扩展的两个全词表版本均发生输出坍缩，未达到开放域对话。

因此，V2.1 的有效结论是：LCM 已形成一个小域、可剥离教师、受认知状态控制的因果语言原型；尚不能称为通用对话模型，也尚未完成真正的被动通道一致性验证。

---

## 1. 研究目标

本报告验证以下问题：

1. Qwen 是否可以只在训练期参与，并将语言能力或语言约束反馈给 LCM 主模型；
2. 最终推理移除 Qwen 后，主动通道是否仍能产生连续中文；
3. 主动输出是否真正依赖认知状态，而不是生成头绕过认知模块完成记忆；
4. 模型是否具备初步因果、反事实、多步与组合能力；
5. 当前认知状态是否可以由外部读取；
6. 新记忆写入与旧记忆保持之间是否存在可测量的冲突；
7. 小域结果能否扩展为开放域对话。

本轮不试图证明 LCM 已经具备通用智能、自主意识或开放域推理能力。所有结论仅限于实际运行的模型、数据与测试范围。

---

## 2. 双通道定义

### 2.1 主动通道

主动通道是模型面向外部交流的语言输出路径。其输入不是直接复制用户文本，而是主模型形成的认知状态 `z_q`。在当前实现中，主动生成头使用因果线性注意力与 GLU，`z_q` 既作为序列前缀，也以残差形式持续注入每个生成位置，以避免状态信息只影响第一个 token 后迅速衰减。

主动通道的训练目标是：梯度必须通过显著改变主模型形成的状态以及主动生成头，使连续输出能够由认知状态塑造。Qwen 不是最终主动通道。

### 2.2 被动通道

被动通道用于外部读取模型当前状态，其设计目的不是生成经过修辞优化的回答，而是尽可能直接、诚实、实用地映射内部状态。模型不应被假定知道该通道正被读取，否则主动表达策略可能反蔽内部状态。

需要严格说明：本轮 V3/V2.1 有效检查点没有保存独立的被动读出头。实验只通过线性探针证明 `z_q` 中存在可读取信息，不能据此宣称真正的主动/被动一致性已经验证。恢复独立只读被动头是下一版的必要工作。

### 2.3 Qwen 的角色

Qwen2.5-0.5B-Instruct 在本轮中有两种训练期用途：

- 在小域实验中，冻结 Qwen，预计算局部词表上的软语言目标；梯度只更新 LCM 学生；
- 在开放域失败扩展实验中，将 Qwen 的 896 维 token embedding 压缩为 64 维学生初始化，尝试迁移静态词义空间。

所有发布的学生检查点均不包含 Qwen 参数；学生推理脚本不加载 Qwen。检查参数树可见其仅包含：`encoder`、`hrq`、`sparse`、`lowrank`、`manifold`、`binding`、`contrast` 和 `gen_head`。

## 3. 模型与训练结构

### 3.1 有效小域学生

| 项目 | 配置 |
|---|---|
| 认知维度 | 64 |
| 编码器 | 2 层，4 头 |
| 主动生成头 | 因果线性注意力 + GLU |
| 认知循环 | 4 个宏步 |
| 认知格 | HRQ、稀疏、低秩、流形、绑定、对比 |
| 输出词表 | 实验语料局部 Qwen token 子集 |
| 教师 | Qwen2.5-0.5B-Instruct，冻结 |
| 推理依赖 Qwen | 否 |

编码器首先将问题映射为初始状态 `z`。认知循环在多类认知格上检索并形成 `z_loop`。早期实验直接使用 `z_loop` 时，不同问题容易收敛到相似终态，导致所有问题输出同一答案。有效版本采用：

\[
z_q = \operatorname{RMSNorm}(z + z_{loop})
\]

该残差保留问题身份，同时不移除认知循环。主动头在每个时间步接收：

\[
e_t' = e_t + 0.5z_q
\]

这使认知状态可以持续塑造完整序列，而不只控制首 token。

### 3.2 损失

小域训练使用三类信号：

\[
L = L_{CE} + \lambda_{KD}L_{KD} + \lambda_m L_{margin}
\]

- `L_CE`：answer-only 教师强制交叉熵；
- `L_KD`：Qwen 在局部词表上的软目标蒸馏；
- `L_margin`：正确认知状态相对零状态的首 token 因果间隔。

后期 Qwen 蒸馏损失与监督 CE 的变化方向不一致：监督 CE 降至约 0.029，而蒸馏项仍约 9.21。因此，本报告不把小域成功归因于 Qwen 蒸馏；更可靠的解释是监督因果数据、状态残差与持续注入共同起作用。

## 4. 数据

### 4.1 小域因果数据

- 20 条基础中文因果问答；
- 20 条对应同义改写；
- 合计 40 条训练输入；
- 另设第三套 20 条未参与训练的改写问题。

主题包括结冰、降雨、植物缺水、电路、融化、撞击、呼吸、水流、溶解、天气、电量、影子、燃烧、睡眠、排水、气球、热传导、通风与复习。

### 4.2 专项数据

- 反事实训练：6 条；测试：4 条未见改写；
- 单跳关系训练：6 条，构成 3 组 `A→B`、`B→C`；组合测试：3 条 `A→C`；
- 直接多步训练：3 条两跳链；测试：3 条未见改写；
- 记忆更新：将“狗通常怎样叫”的答案人为替换为已知的手机关机答案，以便明确测量写入与遗忘，而不是评估事实正确性。

### 4.3 开放域数据

开放域试验使用 `alpaca_gpt4_data_zh.json`：原始 48,818 条，本轮抽取 4,000 条，并加入 100 条因果回放样本。该实验只用于判断语言扩展是否成功，不参与小域因果结论。

## 5. 实验沿革与步数

| 分支 | 步数 | 目的 | 结果 |
|---|---:|---|---|
| 路径混用实验 | 50 | scheduled sampling | 作废：误用完整提示词数据 |
| 小域初始学生 | 100 | answer-only 初测 | 输出坍缩 |
| 认知残差版本 | 500 | 消除统一答案 | 20 个主题可区分，句末重复 |
| EOS 版本 | 500 | 学习终止 | 多数回答可终止，部分局部重复 |
| 同义增强基线 | 800 | 小域因果与改写 | 40/40 训练问法正确 |
| 全词表随机初始化 | 600 | 开放域扩展 | 失败，输出“1，我我……” |
| Qwen 语义嵌入初始化 | 800 | 迁移静态词义 | 失败，输出“1……” |
| 反事实/组合分支 | 400 | 反事实与边组合 | 反事实 3/4，组合 1/3 |
| 直接多步分支 | 300 | 两跳因果改写 | 3/3 |
| 带回放记忆更新 | 200 | 稳定写入 | 写入失败，保留 19/19 |

## 6. 作废实验与工程修复

### 6.1 数据路径混用

早期 intended answer-only 数据保存在 `data/causal_answer_only/train_dialogue.npz`，但训练命令误用了 `data/causal_dialogue/train_dialogue.npz`。后者包含 system、user 和 assistant 全提示词，允许模型从提示序列中获得不应存在的语言捷径。相关 scheduled-sampling 结果全部作废，不进入有效结论。

### 6.2 统一答案坍缩

直接使用认知循环终态时，多个问题生成相同文本。加入 `z + z_loop` 残差后，模型才可以稳定区分问题主题。这说明当前认知循环存在过度收敛倾向；残差是有效修复，也是未来需要进一步解释的结构依赖。

### 6.3 EOS 缺失

未训练 EOS 时，模型能够输出正确主体答案，但在结尾持续重复句号、词语或短语。将 `<|im_end|>` 加入目标后，多数训练样本可以正常结束。

### 6.4 教师强制与自由生成差异

直接 CE 很低并不保证自由生成稳定。早期 scheduled sampling 版本曾退化为重复“的”和句号。后续实验仍观察到局部重复，说明暴露偏差尚未完全解决。

### 6.5 检查点

Qwen 被排除在保存参数之外，避免每个检查点重复保存约 0.5B 教师权重。学生分支均单独保存，失败版本也作为对照保留。

## 7. 小域因果对话结果

同义增强基线训练 800 步后：

- 监督 CE：从 5.807 降至约 0.029；
- 首 token 因果 margin：降至 0；
- 40/40 训练输入生成对应完整答案；
- EOS 正常；
- Qwen 已从推理路径剥离。

第三套未见改写由人工检查，约 11/20 保持正确主题或因果方向，其余样本出现主题错配、短语混合或重复。该 11/20 不是严格自动准确率，不应与后续关键词通过率直接比较。

这一结果支持“小域有限泛化”，不支持开放域对话。

---

## 8. 认知状态干预

在相同问题与解码输入下，仅替换认知状态：

| 条件 | 序列 CE | 首 token 准确率 |
|---|---:|---:|
| 正确 `z_q` | 0.0323 | 100% |
| 全零状态 | 3.1031 | 0% |
| 样本间循环错配 | 4.5426 | 0% |

相对正确状态：

- 归零使 CE 增加约 3.071；
- 错配使 CE 增加约 4.510；
- 错配比归零更差。

这表明认知状态不仅包含有用信息，而且实际控制主动输出。若生成头完全绕过认知状态，归零或错配不应造成如此系统性的下降。错配比归零更差也符合“错误状态提供定向误导”的解释。

但该实验仍不能证明认知格内部形成了人类式推理过程；它只证明 `z_q` 是输出的必要条件变量。

---

## 9. 状态可读性与通道一致性

在 `z_q` 上训练简单线性探针，预测回答首 token 类别。留出样本准确率为 100%。主动头在对应基线上的首 token 准确率同样为 100%。

该结果说明：

1. 回答类别信息在线性层面存在于认知状态中；
2. 主动通道读取的信息与探针可读取的信息在小域内一致；
3. `z_q` 并非不可解码的随机控制信号。

局限是：留出样本包含相同答案的语言改写，训练集极小，探针可能读取主题类别而不是完整内部内容。此外，探针不是正式被动通道。V2.1 对“被动通道诚实性”的结论只能写为尚待验证。

## 10. 反事实

### 10.1 零样本

基线面对“条件已被取消，原结果是否仍发生”的四个问题时为 0/4。模型忽略否定条件，直接回放原始因果答案。例如：

- 输入：植物得到充足水分，是否仍会因缺水萎蔫；
- 基线输出：植物会因缺水萎蔫并可能死亡。

这说明基础因果训练学到的是正向映射，不自动包含前提撤销能力。

### 10.2 专项训练

加入 6 条反事实训练样本并训练 400 步后，4 条未见改写中 3 条包含正确的“不会”方向。植物样本仍失败，并出现重复与混合文本。

这里的 `3/4` 按关键结论词判定。例如某些输出虽然包含“不会”，后续解释仍有语义混合，因此不能解释为 75% 的完整高质量反事实回答率。更准确的结论是：反事实方向可以被专项训练迁移到未见改写，但语言完整性和旧记忆抑制仍不稳定。

## 11. 多步因果与组合泛化

### 11.1 直接多步训练

训练三条两跳链，再用不同说法测试：

- 雨使地面湿润，随后降至冰点 → 水结冰；
- 纸燃烧释放热量 → 周围温度升高；
- 运动提高需氧量 → 呼吸加快。

未见改写测试达到 3/3，输出均完整、主题正确。这证明模型可以学习两跳因果回答结构，并对句式改写保持稳定。

### 11.2 组合泛化

另一分支只训练单跳 `A→B` 与 `B→C`，从未提供 `A→C` 完整答案。测试结果为 1/3：

- 雨 → 地面湿 → 降温 → 结冰：成功；
- 手机没电 → 关机 → 恢复电能：失败，仍输出关机；
- 纸达到燃点 → 燃烧 → 释放热量：失败，停留在燃烧或反事实模板。

这一区分非常关键。直接多步 3/3 说明模型能学习多步模板；组合 1/3 说明它尚未稳定形成可组合关系运算。一次成功只能视为初步信号，不能宣称已获得系统性链式推理。

## 12. 记忆更新与稳定—可塑性

为了隔离事实常识的影响，实验人为规定：“狗通常怎样叫”的新答案改为原有的“手机会因无法获得电能而关机”。该目标本身不是现实知识，而是测试模型能否覆盖旧映射。

### 12.1 带回放更新

- 训练：200 步；
- 新记忆：0/1；
- 其余旧记忆：19/19。

旧映射“狗会汪汪叫”保持不变。说明回放有效保护旧知识，但当前比例和更新方法使模型无法写入冲突记忆。

### 12.2 无回放强制更新

- 训练：120 步；
- 新记忆：1/1；
- 其余旧记忆：1/19。

模型成功把狗问题改写为手机答案，但几乎所有其他问题也开始输出手机关机文本，形成灾难性遗忘与全局坍缩。

### 12.3 结论

当前模型不是“无法更新”，而是缺少局部可塑性机制：

- 强保护 → 无法覆盖；
- 强更新 → 全局覆盖。

后续应把更新限制到相关记忆格或局部适配参数，并配合稀疏梯度、重要性约束或分区回放，而不是在全模型上二选一。

## 13. 开放域扩展失败对照

### 13.1 全词表随机初始化

模型扩展到 Qwen 的 151,936 token 全词表，使用 64 维共享 embedding 和低秩输出以控制内存，在 4,000 条通用指令数据上训练 600 步。CE 从 13.45 降到 8.12，但十个开放问题均退化为类似“1，我我……”的重复输出。

### 13.2 Qwen 语义 embedding 初始化

将 Qwen 896 维 embedding 随机投影并归一化到 64 维，训练 800 步。输出仍统一坍缩为“1……”及句点重复。

### 13.3 解释

完整词表只决定允许输出哪些 token，不会自动提供语言生成能力。embedding 压缩最多迁移静态词义邻域，不能迁移 Qwen 多层 Transformer 的序列动力学。单层 64 维主动头、4,000 条数据和数百步训练不足以从头重建开放域中文模型。

因此，V2.1 不具备开放域对话能力。开放域失败不否定小域认知干预结果，但限制了其外推范围。

---

## 14. 主要结论

### 已得到实验支持

1. Qwen 可以从最终推理结构中完全移除；
2. 学生主动通道能够独立生成连续的小域中文因果回答；
3. 认知状态归零或错配会使输出显著退化，证明主动输出受 `z_q` 因果控制；
4. 小域认知状态可由简单线性探针读取；
5. 反事实方向可以通过专项训练获得有限改写泛化；
6. 直接训练过的两跳结构可以泛化到新句式；
7. 记忆系统存在清晰、可复现的稳定—可塑性冲突。

### 尚未得到支持

1. 开放域正常对话；
2. 稳定的零样本反事实；
3. 稳定的 `A→B→C` 组合推理；
4. 新知识局部写入且不破坏旧知识；
5. 真正被动通道与主动回答的一致性；
6. 被动通道的开放域诚实性；
7. Qwen 软目标蒸馏本身是小域成功的主要来源。

## 15. 威胁与限制

### 数据规模

主要有效实验只有 20 个基础主题。即使加入同义改写，语义覆盖仍极窄。

### 测试独立性

部分“留出”样本与训练样本共享答案和主题，只改变表达方式，因此测试的是改写鲁棒性，不是新知识泛化。

### 指标定义

反事实和组合测试使用关键词判定。关键词正确不代表整句逻辑、语法和解释均正确。报告同时保留原始输出，避免只看通过率。

### 模型容量

64 维、浅层主动头适合快速验证认知控制链路，不足以承担开放域语言建模。

### 被动通道缺失

线性探针不能替代正式被动读出。被动通道必须重新加入，并明确停止其梯度回流，才能测试“只读、诚实而实用”的设计目标。

### 人工构造任务

记忆更新使用人为错误映射；它适合测工程性质，不代表模型现实事实能力。

## 16. 下一版实验建议

### 16.1 恢复真正被动通道

- 增加独立 `W_passive`；
- 默认对被动头使用 `stop_gradient(z_q)`，防止读出任务反向塑造被读取状态；
- 对比主动回答、被动读出、线性探针和真实标签；
- 测试冲突时是主动修辞变化，还是内部状态本身变化。

### 16.2 稳定—可塑性机制

- 仅更新被路由命中的格或新增记忆槽；
- 冻结高重要性参数；
- 使用新旧样本自适应回放比例；
- 分别报告写入成功率、非相关记忆保持率和输出坍缩率。

### 16.3 组合推理

- 构造更大的符号化关系图；
- 严格隔离边训练集与路径测试集；
- 比较直接多步训练、单边训练和打乱边负对照；
- 干预中间状态，验证第二跳是否依赖第一跳结果。

### 16.4 主动语言模型

开放域版本需要至少 256 维、4–8 层学生解码器，并蒸馏 Qwen 的 top-k logits 或中间隐藏状态。训练顺序应是先迁移序列语言能力，再接认知状态条件与因果训练，而不是用少量指令数据从随机生成头直接起步。

### 16.5 评估规范

- 固定 train/dev/test；
- 保存随机种子、完整配置、日志与周期检查点；
- 每个结论至少运行多个随机种子；
- 自动指标与人工评估分开报告；
- 所有失败输出保留，不只展示成功样本。

## 18. 最终判断

LCM V2.1 已经越过了“主动头是否真正受认知状态影响”这一关键验证点。状态干预给出了强而直接的证据：正确、归零和错配状态会产生系统性不同的输出损失与首 token 行为。模型也能在剥离 Qwen 后生成连续的小域因果文本，并通过专项训练获得有限反事实和多步能力。

但当前系统仍是小域原型。它没有开放域语言能力，没有稳定组合推理，没有解决新旧记忆冲突，也没有真正实现并验证独立被动通道。V2.1 最合理的定位不是“已完成的通用认知模型”，而是“认知状态能够因果塑造独立主动语言通道”的工程证据，以及下一阶段研究问题已经被清晰定位的实验基线。
