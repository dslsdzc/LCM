## 阅读建议

- **第一次接触 LCM**：从 `a.md`（或 `a_cn.md`）开始，了解整体架构与设计理念。
- **需要实现或修改格**：`b.md` 包含所有格的完整数学定义和实现细节。
- **关注推理性能**：`c.md` 描述零参数推理引擎的设计与接口。
- **安全审计**：`d.md` 定义安全体系的三层结构和硬中断协议。
- **自我意识与元认知**：`e.md` 描述自观测、反射回路和因果主体等高层模块。
