# LCM 晶格存储命题正式验证（V2.1）

## 命题

> 学生模型的概念信息确实进入晶格，而不是由编码器和主动生成头绕过晶格完成任务。

## 实验控制

- 教师：Qwen2.5-0.5B-Instruct，仅生成软目标；学生权重不包含 Qwen。
- 学生：`d_model=64`，相同参数规模、数据、初始化规则和 800 个训练步。
- 数据：20 条基础因果问答及 20 条训练改写；测试采用第三套未见问法。
- 独立重复：随机种子 7、17、27。
- 三种认知状态路径：
  - `residual`：`normalize(z_encoder + z_lattice)`（当前结构）；
  - `encoder_only`：`normalize(z_encoder)`；
  - `lattice_only`：`normalize(z_lattice)`。
- 主要指标：未见问法上的自由自回归生成，而非仅使用 teacher forcing。

## 三随机种子结果

| 状态路径 | 完全正确（/20） | 字符序列相似度 | 不同回答数量 |
|---|---:|---:|---:|
| residual | 9.33 | 0.666 | 17.0 |
| encoder_only | 9.67 | 0.648 | 17.0 |
| lattice_only | 1.67 | 0.220 | 2.0 |

逐种子完全正确数：

- residual：9、10、9；
- encoder_only：11、10、8；
- lattice_only：2、2、1。

## 干预结果（seed 7）

对当前 residual 学生进行同权重干预：

| 条件 | 交叉熵 | Token 准确率 | 相对正常 CE |
|---|---:|---:|---:|
| 正常 encoder + lattice | 0.705 | 0.808 | 0 |
| encoder only | 0.877 | 0.771 | +0.172 |
| 跨样本打乱 lattice | 0.725 | 0.808 | +0.020 |
| 固定 lattice | 0.718 | 0.805 | +0.013 |
| lattice only | 2.182 | 0.490 | +1.477 |
| zero state | 3.103 | 0.418 | +2.398 |

晶格输出样本间方差为 `1.01e-5`。晶格对当前 residual 模型有可测影响，但打乱或固定晶格只造成很小退化。

## Teacher forcing 陷阱

`lattice_only` 学生在 teacher-forced 条件下可达到很高 token accuracy，但自由生成仅产生 1–3 种答案并发生模式塌缩。这是因为生成头读取了正确答案的前序 token。故 teacher-forced CE 不能单独证明认知状态包含概念信息。

## 结论

在本实验规模和训练方式下，第一个命题**未通过**：

1. 当前 residual 模型没有稳定优于同规模 encoder-only 对照；
2. encoder-only 可以独立完成同等水平的未见问法生成；
3. lattice-only 在三种随机种子上均发生自由生成模式塌缩；
4. 打乱或固定 residual 模型的 lattice 状态只造成轻微退化。

因此，现有证据支持“晶格参与了计算”，但不支持“主要概念信息已经存储在晶格中”。直接原因是主动状态存在 `z_encoder + z_lattice` 旁路，且训练目标没有要求晶格单独保留可区分的概念信息。

## 下一实验

下一版应在保持主动通道设计的同时增加真正的信息瓶颈，并重新执行相同三种子实验：

1. 限制主动生成头直接读取完整 `z_encoder`；
2. 为问题身份提供低容量投影，认知内容必须经过晶格；
3. 增加晶格状态区分度与概念重构损失；
4. 继续以自由自回归生成作为主要判据；
5. 保留 encoder-only 等参数对照，避免把语言头记忆误判为晶格存储。
