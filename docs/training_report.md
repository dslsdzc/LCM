# LCM 训练实验报告

> 从 GTX 1650（4GB）到 RTX 5090（32GB），从自训语言模型到 Qwen 冻结集成

---

## 环境总览

| 项目 | 说明 |
|------|------|
| 硬件 | GTX 1650 (4GB) → RTX 5090 (32GB) |
| 框架 | JAX 0.4.29 / 0.10.2 + Optax |
| 数据 | 中文维基百科（zhwiki） |
| Tokenizer | BPE, V=30,000 |
| 训练 tokens | ~540M (zhwiki) |

---

## 实验 A1：原始语言 LCM（无位置编码）

**时间线：** Stage 1 初始训练

| 参数 | 值 |
|------|-----|
| 层数 | 4 |
| d_model | 256 |
| 参数量 | ~23M |
| Batch | 4 |
| Seq len | 256 |
| Optimizer | AdamW |
| Steps | 110,000 |
| 位置编码 | ❌ 无 |
| Codebook soft read | 有（6种） |

**学习曲线（step vs PPL）：**

| Step | Loss | PPL |
|------|------|-----|
| 100 | 8.58 | 5,300 |
| 500 | 6.49 | 658 |
| 1,000 | 2.21 | 9.1 |
| 3,300 | 0.17 | 1.2 |

**结论：** PPL 1.2 过拟合。模型只学会了词汇分布和局部 n-gram，语法不成立。生成测试输出为中文词汇碎片拼凑，不成句。

---

## 实验 A2：续跑 + 无位置编码

**说明：** 从原始 final checkpoint 继续训练

| 参数 | 值 |
|------|-----|
| Steps | 15,000（续跑） |
| PPL 终点 | ~10.4 |

**结论：** PPL 不再下降，模型容量到极限。

---

## 实验 A3：从零 + 位置编码（10K 步）

**说明：** 确认位置编码的必要性

| 参数 | 值 |
|------|-----|
| Steps | 10,000 |
| 位置编码 | ✅ 有 |
| PPL 终点 | 1.0（过拟合） |

**学习曲线：**

| Step | Loss | PPL |
|------|------|-----|
| 800 | 3.89 | 49.1 |
| 900 | 2.87 | 17.6 |
| 1,000 | 2.21 | 9.1 |
| 6,900 | 0.05 | 1.0 |

**结论：** 位置编码有效但模型仍过拟合。4 层 d=256 容量不足以学语法。

---

## 实验 A4：8 层 + mHC + MTP + codebook soft read（50K 步）

**理论来源：** DeepSeek-V4（mHC, MTP）

| 参数 | 值 |
|------|-----|
| 层数 | 8 |
| d_model | 256 |
| n_hc (mHC) | 2 |
| MTP depth | 2 |
| Codebook | 6×512 shared entries |
| Steps | 50,000 |
| 最终 PPL | 1.5 |
| Optimizer | AdamW |

**学习曲线：**

| Step | Loss | PPL |
|------|------|-----|
| 100 | 11.06 | 63,390 |
| 1,000 | 4.48 | 88.3 |
| 5,000 | 0.98 | 2.7 |
| 25,000 | 0.58 | 1.8 |
| 49,000 | 0.38 | 1.5 |

**结论：** mHC + MTP 缓解了早期过拟合（PPL 1.5 vs 1.0），但生成测试仍无法输出通顺中文。

---

## 实验 A5：Qwen2.5-0.5B 冻结集成

**转折：** 放弃自训语言模型，使用预训练模型

| 方案 | 说明 |
|------|------|
| 语言能力来源 | Qwen2.5-0.5B（冻结） |
| 解码器 | 8 层 d=256（可训练，含 mHC）|
| 桥接 | proj_down (896→256) + proj_up (256→896) |
| 认知训练目标 | 编码器 + 码本 + 投影层 |

**NaN 问题：**
- Qwen 传入优化器 → 动量 slot 被 NaN 梯度污染 → 全参数 NaN
- 修复：Qwen 完全排除在优化器之外

## 关键教训汇总

| 发现 | 结论 |
|------|------|
| 4L d=256 必过拟合 | 容量不够学语法 |
| 8L + mHC + MTP 改善但不够 | 25M 参数语言模型天花板 |
| Codebook soft read 梯度弱 | 随机条目 → 均匀权重 → 零信号 |
| Qwen 冻结可行但需隔离优化器 | `stop_gradient` 不够，需从 optimizer.init 排除 |
| JIT 编译内存 > 运行时内存 | 3090/5090 以上才舒适 |
| AI 研究院接手前需修复 | training_log、checkpoint 管理、NaN 防护 |
