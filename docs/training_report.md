## 实验 A：原始语言模型训练序列

### A1：4 层 + codebook，110K 步（无日志）

**说明：** 原始训练。training_log.txt 不存在，曲线不可追溯。已知生成测试输出为中文碎片拼凑，不成句。

### A2：从 final 续跑 5K 步（step 115000→119600）

**参数：** lr=1e-4, B=4, N=256, 有 pos_embed（续跑时新增）

| Step | Loss | PPL |
|------|------|-----|
| 115,000 | 0.11 | 1.1 |
| 115,100 | 7.89 | 2,674（pos_embed 新增导致重置）|
| 115,500 | 1.08 | 2.9 |
| 119,600 | 0.04 | 1.0 |

**结论：** 加 pos_embed 后 PPL 短暂重置（从 1.1 到 2674），然后快速回落到 1.0。仍过拟合。

### A3：从 final 续跑 6K 步（step 120000→125900）

**参数：** lr=1e-4, B=4, N=256, 无 pos_embed

| Step | PPL |
|------|-----|
| 125,700 | 12.2 |
| 125,800 | 10.9 |
| 125,900 | 10.4 |

**结论：** 续跑后 PPL 稳定在 ~10.4，模型已到容量极限。

### A4：从零 + 位置编码 10K 步

**参数：** lr=3e-4, B=4, N=256

| Step | PPL |
|------|-----|
| 10,100 | 1.0 |
| 10,200 | 1.0 |
| 10,300 | 1.0 |

**结论：** 位置编码有效但模型早期过拟合。4 层 d=256 容量不足。

### A5：8 层 + mHC + MTP + codebook，50K 步

**参数：** lr=3e-4, B=4, N=256, n_hc=2, MTP depth=2, codebook 6×512

| Step | PPL |
|------|-----|
| 49,700 | 1.5 |
| 49,800 | 1.5 |
| 49,900 | 1.5 |

**生成测试（50K 步 checkpoint）：**

```
Prompt: 今天天气
Output: 今天天气er���豪强机能�二次大战使徒�的形成�一期�跟踪称之�
年起������对外关系豪强长老ocial氩椭
```

**结论：** mHC + MTP 缓解了早期过拟合（PPL 1.5 vs 1.0），但生成仍不成立。
PPL 是局部 n-gram 记忆的胜利，不是语言理解。

## 实验 B：Qwen2.5-0.5B 冻结集成 + Stage 2 认知训练

| 组件 | 说明 |
|------|------|
| 语言能力 | Qwen2.5-0.5B（冻结，排除在优化器外）|
| 认知模块 | 编码器 + 6 码本 + 认知循环（32 步）|
| 桥接 | z_proj (896×256) |
| 硬件 | RTX 5090 (32GB) |
| 达到步数 | 18,000（磁盘满中断）|

**NaN 问题：** Qwen 误传入优化器 → 动量 slot 被污染 → 全参数 NaN。
修复：Qwen 排除在 optimizer.init 外。

**工程问题：**
- training_log.txt 未在 cog_train 中实现
- checkpoint 2GB/个，50GB 数据盘存 19 个后满
- tqdm 进度条被 NaN 阻断

## 关键教训

| 发现 | 结论 |
|------|------|
| 4L d=256 必过拟合 | 小 transformer 学不了语法 |
| 8L + mHC + MTP 改善有限 | 25M 参数是天花板 |
| Qwen 冻结可行但需隔离 NaN | stop_gradient 不够，需排除出 optimizer |
| training_log 需在 cog_train 中实现 | 否则曲线丢失 |
