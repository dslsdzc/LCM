# LCM 第 4 命题：新知识学习中的旧知识与旧能力保持

## 命题

> 新知识进入后，旧知识和旧能力不会严重退化；系统必须同时具备稳定性与可塑性，而不是通过冻结全部模型拒绝学习。

本报告验证的是受控组合因果任务中的顺序持续学习。成功必须同时满足旧能力保持、新知识掌握、旧晶格不漂移和跨随机种子稳定。

## 数据与顺序训练

- 总容量：16 个原因晶格单元、11 个条件晶格单元。
- 阶段 A：只训练旧域的 12 个原因和 8 个条件。
- 阶段 B：激活此前未使用的 4 个原因单元和3 个条件单元。
- 旧域：77 个训练组合、19 个未见测试组合。
- 新域：64 个训练组合、16 个未见测试组合。
- 新测试组合在阶段 A 中完全不可见。
- 最终实验每个种子阶段 A 2,500 步、阶段 B 3,000 步；随机种子 7、17、27。
- 每阶段权重分别保存，可以直接比较学习前后状态。

## 预注册判据

| 判据 | 阈值 |
|---|---:|
| 阶段 A 旧任务平均整句准确率 | ≥ 90% |
| 任一种子旧任务下降 | ≤ 5 个百分点 |
| 阶段 B 新任务平均整句准确率 | ≥ 80% |
| 新任务三种子标准差 | ≤ 5 个百分点 |
| 受保护旧晶格单元最大漂移 | ≤ `1e-7` |

没有把 1/19＝5.263% 四舍五入为 5%。前两轮出现单个旧样本退化时均判定失败并继续定位。

## 对照与失败定位

### 无保护顺序微调

使用相同初始化、数据与训练步数，但不保护旧晶格、不回放旧数据：

- 新知识平均准确率：93.75%。
- 旧知识平均下降：12.28 个百分点。
- 各种子旧知识下降：10.53%、10.53%、15.79%。
- 旧晶格/路由参数最大漂移约 0.20–0.31。

这说明离散晶格并不会自动消除遗忘。新样本的软检索梯度、共享生成头和词表竞争仍能修改旧行为。

### 只冻结旧晶格、回放与蒸馏

- 旧晶格漂移降为 0。
- 新知识平均达到 97.92%。
- 但两个种子仍各有一个旧组合错误，即 5.263% 下降，未达到 5% 门槛。

定位表明错误不在记忆单元，而在共享生成头学习新 token 后发生的输出映射漂移。

### 冻结整个语言头

- 旧能力下降：0。
- 新知识平均准确率：25%。

这验证了单纯冻结可以获得稳定性，却破坏可塑性，不能作为命题通过证据。

### 组件级隔离

最终方案：

1. 冻结已占用的旧原因/条件晶格值与路由键。
2. 新知识只写入未占用晶格单元和新路由。
3. 冻结语言头共享动力学及旧 token 的 embedding/输出列。
4. 只开放新 token 的 embedding 与输出列。
5. 使用旧样本回放和旧模型 logits 蒸馏，保护共享行为。
6. 将硬晶格路由延伸到输出域：只检索到旧单元时，新词列不参与竞争；检索到新单元时才开放新词。

输出域屏蔽由模型实际检索到的晶格索引决定，不读取答案标签或测试集身份。

## 最终结果

| Seed | 旧能力阶段 A | 学新知识后旧能力 | 旧能力下降 | 新知识准确率 | 旧格漂移 |
|---:|---:|---:|---:|---:|---:|
| 7 | 94.74% | 94.74% | 0 | 100% | 0 |
| 17 | 100% | 100% | 0 | 100% | 0 |
| 27 | 100% | 100% | 0 | 100% | 0 |
| 平均 | **98.25%** | **98.25%** | **0** | **100%** | **0** |

新知识准确率标准差为 0；旧原因和条件路由准确率训练前后均为 100%。所有预注册判据通过，`complete_pass = true`。

## 因果解释

实验区分了三种干扰来源：

- **晶格内容干扰**：通过旧单元梯度屏蔽消除。
- **共享生成动力学漂移**：通过核心冻结、回放和蒸馏消除。
- **新旧词表竞争**：通过由晶格路由控制的输出域隔离消除。

与此同时，新晶格值、路由以及新词绑定保持可训练，因此新知识达到 100%，并非靠拒绝学习来保持旧能力。

## 结论

在当前受控组合持续学习任务中，命题完整通过：

> 新知识可以写入未占用晶格单元，并在不改变旧晶格、不降低旧测试能力的情况下形成新输出能力。稳定性和可塑性可以同时成立。

更准确地说，避免灾难性遗忘不是“晶格天然离散”单独带来的，而是离散单元隔离、共享部分保护、回放蒸馏和路由化输出绑定共同实现的。

## 外部有效性边界

当前只证明一次域扩展、有限容量与受控符号化因果任务。尚未证明：

- 多轮连续任务后的长期保持；
- 晶格容量耗尽后的扩容与合并；
- 自然语言开放域中的语义漂移；
- 相互矛盾的新旧事实如何版本化共存。

下一阶段应执行 5–10 个连续任务、延迟回测和容量压力实验，继续使用最坏种子下降而非只看平均值。
