# LCM 第 2 命题：认知状态因果贡献完整验证报告

## 命题定义

第 2 命题为：**正确认知状态 `z_q` 对主动通道输出具有真实因果贡献**。验证目标不是模型“看起来会说话”，而是在保持问题、模型权重和解码过程不变时，仅干预 `z_q` 就能可预测地改变回答；正确 `z_q` 还必须稳定优于无状态、零状态、随机状态和跨问题错配状态。

本实验沿用第 1 命题通过后保存的三个 student-only 权重。Qwen 在训练后已剥离，本评估没有加载 Qwen 参数、教师概率或隐藏状态。

## 实验对象与控制

- checkpoint：seed 7、17、27，各训练 2,000 步。
- 测试集：19 个训练期间从未出现的原因–条件组合。
- 固定项：问题、学生模型参数、生成算法和输出长度。
- 唯一自变量：输入主动生成器的认知状态。
- 推理方式：自由自回归贪心生成；另计算教师强制交叉熵。
- 随机对照：每个 checkpoint 进行 100 次与正确 `z_q` 逐样本等范数的随机状态采样，共 300 次。
- 训练型语言头对照：使用完全相同的 decoder、数据划分、优化器、scheduled sampling 和每种子 2,000 步预算，但认知状态始终为零；三个种子额外训练共 6,000 步并保存独立权重。

五种主要条件：

1. `correct_zq`：当前问题检索得到的正确认知状态。
2. `no_zq`：主动通道不获得认知输入。
3. `zero_zq`：形状匹配的全零认知状态。
4. `random_norm_matched_zq`：方向随机但范数与正确状态相同。
5. `shuffled_question_zq`：来自另一个问题的训练后状态。

`no_zq` 与 `zero_zq` 在当前生成接口中数学等价，但分别保留为结构消融语义和张量干预语义；两者数值结果应完全一致，这也构成实现一致性检查。

## 预注册标准

| 标准 | 阈值 |
|---|---:|
| 正确状态未见组合整句准确率 | ≥ 80% |
| 正确状态相对最佳对照优势 | ≥ 40 个百分点 |
| 正确状态交叉熵 | 低于所有对照 |
| 组件交换反事实准确率 | ≥ 90% |
| 正确状态三种子准确率标准差 | ≤ 5 个百分点 |
| Qwen 独立性 | 不加载 Qwen |
| 主动通道到晶格梯度 | 有限且非零 |
| 重新训练的 head-only 整句准确率 | ≤ 10% |

## 主要结果

| 状态条件 | 整句准确率 | token 准确率 | 原因事实 | 条件事实 | 交叉熵 |
|---|---:|---:|---:|---:|---:|
| 正确 `z_q` | **100%** | **100%** | **100%** | **100%** | **0.00863** |
| 无 `z_q` | 0% | 55.26% | 8.77% | 12.28% | 1.69715 |
| 零 `z_q` | 0% | 55.26% | 8.77% | 12.28% | 1.69715 |
| 跨问题错配 `z_q` | 0% | 51.32% | 0% | 5.26% | 4.32146 |
| 等范数随机 `z_q` | 0.35% | 55.16% | 8.37% | 12.28% | 2.64600 |

正确状态相对最佳对照的整句优势为 99.65 个百分点。正确状态三种子的整句准确率标准差为 0。关系 token 和 EOS 在错误状态下仍可能由生成器语言先验产生，因此整句准确率、原因事实和条件事实才是主要因果指标。

## 训练型语言头独立完成对照

仅在推理时清零状态可能受到分布偏移质疑，因此另外从头训练三个同构语言头。训练时始终不给 `z_q`，但保留与认知模型相同的全部语言头参数和训练预算。

| Head-only Seed | 整句准确率 | token 准确率 | 原因事实 | 条件事实 |
|---:|---:|---:|---:|---:|
| 7 | 0% | 53.95% | 5.26% | 10.53% |
| 17 | 0% | 53.95% | 5.26% | 10.53% |
| 27 | 0% | 55.26% | 5.26% | 15.79% |
| 平均 | **0%** | 54.39% | 5.26% | 12.28% |

语言头能学会固定的关系和 EOS 形式，因而 token 准确率约 54%；但它不能确定任务相关的原因和条件，三个种子都无法生成一条完全正确的序列。这说明结果不是清零造成的瞬时故障，也不是增加训练时间即可由语言头先验补偿。

## 静态信息流审计

- decoder 的输入只有 `previous_answer_tokens` 和 `z_q`。
- decoder 不接收问题 token、路由 logits、encoder state 或 Qwen state。
- student checkpoint 顶层参数组仅包含 router、lattice、decoder，不存在 Qwen 参数。
- 问题信息只能先决定硬晶格索引，再以晶格值形式进入生成器。

## 方向性反事实干预

只交换原因晶格单元、保留条件单元时，输出采用供体原因且保留原条件；只交换条件单元时则相反。排除供体与原样本对应因素相同的无效样本后：

- 供体组件采用率：100%。
- 未交换组件保持率：100%。
- 完整反事实序列准确率：100%。
- 三 checkpoint、两种组件交换的合计均值：100%。

这排除了“任意扰动都会让输出变差”这一较弱解释：状态干预不只破坏输出，还能按指定的晶格组件方向重写输出，同时保留未干预组件。

## 梯度通路审计

在相同 held-out batch 上，从主动生成损失反传：

| Seed | `||dL/dz_q||` | 原因晶格梯度范数 | 条件晶格梯度范数 |
|---:|---:|---:|---:|
| 7 | 0.02591 | 0.02618 | 0.02600 |
| 17 | 0.04328 | 0.04344 | 0.04322 |
| 27 | 0.06827 | 0.06845 | 0.06736 |

所有梯度均有限且非零，说明反馈并非停留在被动观察层：主动通道的 token 损失确实能够经 `z_q` 反传并塑造两类晶格值。

## 判定

包含训练型 head-only 对照在内的八项标准全部通过，`complete_pass = true`。在当前受控组合因果实验边界内，第 2 命题得到完整支持：

> 正确认知状态是主动输出内容的必要且具有方向性的因果变量；它不只是相关前缀，也不是 Qwen 语言能力的伪影。主动损失到晶格的梯度链路真实存在。

## 外部有效性边界

本结论适用于当前硬边界 student-only 组合任务。它尚未单独证明自然语言开放域中的相关性、事实一致性与表达偏好都能达到同样强度。开放域阶段应保持本报告的五条件干预与组件交换方法，不能仅用主观对话样例替代。
