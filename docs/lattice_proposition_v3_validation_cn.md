# LCM 晶格存储命题 v3 严格验证报告

## 结论

在本次**受控组合因果实验**的预注册判据下，命题通过：用于生成的因果概念值必须经过离散晶格单元，编码器仅产生寻址信号，主动生成器没有编码器残差旁路。三个随机种子在未见组合上的整句准确率均为 100%；清零或打乱晶格后整句准确率均为 0%。

这证明的是“硬边界、有限组合任务中的晶格因果承载”。它不等价于已经证明原始六晶格在自然语言开放域中完全成功；后者仍需更大语料和真实语言模型实验。

## 实验设计

- 原子因素：12 个原因、8 个条件，共 96 个原因–条件组合。
- 训练集：77 个组合；测试集：19 个从未出现在训练中的组合。
- 无泄漏检查：训练/测试组合交集为 0；两侧均覆盖全部 12 个原因和 8 个条件。
- 输出：4 token 的组合因果序列（关系、原因结果、条件修饰、EOS）。
- 路径约束：`输入 → 路由距离 → 硬晶格索引 → 晶格值 → 生成器`。
- 禁止路径：生成器不接收 encoder state、route logits 或 Qwen 隐状态。
- 训练：每个种子 2,000 步，后半程最高 50% 前缀扰动，包含错误状态整序列排序损失。
- 权重：种子 7、17、27 分别独立保存，推理不依赖 Qwen。

## 预注册判据与结果

| 判据 | 阈值 | 结果 | 状态 |
|---|---:|---:|---|
| 未见组合整句准确率 | ≥ 80% | 100% | 通过 |
| 晶格清零准确率下降 | ≥ 50 个百分点 | 100 个百分点 | 通过 |
| 晶格打乱准确率下降 | ≥ 40 个百分点 | 100 个百分点 | 通过 |
| 原因/条件路由准确率 | ≥ 90% | 100% | 通过 |
| 三种子正常准确率标准差 | ≤ 5 个百分点 | 0 | 通过 |

三种子均得到相同的核心结果：正常推理 100%，打乱晶格 0%，晶格清零 0%，原因单独交换 0%。条件单独交换为 5.26%，来自 19 个样本循环交换时恰有一个条件相同；这与干预定义一致，不是生成保持不变。

## 因果解释

高正常分数本身不足以证明存储位置。这里的关键证据是：

1. 测试组合没有被训练过，排除了逐句记忆全部答案。
2. 生成器只有晶格值这一条来自问题的语义通路。
3. 保持模型参数和输入不变，仅替换晶格值，输出按被替换的原因或条件变化。
4. 清零与固定晶格使任务失败，说明路由器或生成头不能单独恢复答案。
5. 三个随机初始化结果一致，排除了单次偶然收敛。

因此，在该实验边界内，“编码器负责寻址、晶格单元承载可生成概念、主动通道读取晶格后形成连续输出”得到了直接因果支持。

## 限制与下一步

- 当前输出为受控符号化因果语言，不是自由中文对话。
- 当前采用两个因子化晶格，而不是原项目全部六种专用晶格的联合路由。
- 路由类别在训练中有监督，尚未证明开放域概念能完全自组织形成格。
- 下一阶段应把同一硬边界接到真实 tokenizer 与语言主动通道，使用自然语言释义、实体替换和跨模板测试；判据仍应保留零值、固定、打乱和组件交换干预。
