# e — 自我意识研究

## 概述

LCM 的自我意识不是哲学概念，而是工程化的**认知自观测与自调制**能力。系统通过多个独立模块构成一个分层反射架构：

- **底层**：黑匣子（`observability.py`）记录每步推理的原始轨迹，不做判断
- **中层**：叙事记忆（`narrative_memory.py`）筛选重要事件，因果主体（`causal_subject.py`）追踪行为与效果的因果关系
- **高层**：反射回路（`reflection_loop.py`）离线分析长期模式，行为探索器（`behavior_explorer.py`）试错学习路由偏置

这些模块不参与实时推理循环，它们读取轨迹、产生见解、调制参数——但推理引擎本身仍然是无状态的纯函数。自我意识是**寄生在推理引擎之上的元系统**。

核心约束：所有自观测模块的总计算开销不超过推理引擎的 5%，且任何自观测故障不影響推理正确性。

## 一、自观测栈架构

```
推理引擎 (engine.c)
    │ 每步: z_cur → [DAG 推理] → z_next
    │
    ├──→ 黑匣子 (ObservabilityRecorder)
    │     记录: z_cur, z_next, 格权重, 置信度, 冲突标志, 耗时
    │     存储: 环形缓冲区 (raw) + 下采样长期存储 (long-term)
    │
    ├──→ 叙事记忆 (NarrativeMemory)
    │     筛选: 意外事件 (预测偏差大)、冲突事件、新奇路由模式
    │     存储: 重要性排序的长期记忆
    │
    ├──→ 预测缓存 (PredictCache)
    │     记录: (sig, z_cur, z_next) 三元组
    │     用途: 预测复用 + 好奇心驱动探索
    │
    └──→ 因果主体 (CausalSubject)
          构建: 因果图, 追踪行动-效果链
          输出: agency_tension, agency_explore 调制器
```

### 时序约束

| 模块 | 运行频率 | 延迟容忍 | 阻塞 |
|------|---------|---------|------|
| 黑匣子记录 | 每步 | 0 | 否（纯 append） |
| 预测缓存 | 每步（可选）| < 推理引擎单步时间 | 否（可跳过） |
| 叙事记忆 feed | 每步 | 0 | 否（纯 append） |
| 因果主体 step | 每步 | < 推理引擎单步时间 | 否（异常容错） |
| 反射回路 | 每 N 步 (N=200) | 高 | 否（独立线程/协程） |
| 行为探索 | 每 M 步 (M=10) | 中 | 否（非 jitted 调用） |
| 内在动机反思 | 每 1000 步 | 高 | 否 |

## 二、黑匣子：原始数据记录

### 记录内容

每步推理记录一条 `StepRecord`：

```python
@dataclass
class StepRecord:
    step: int                    # 全局步骤号
    source: int                  # 0=外部输入, 1=自生成
    step_time_ms: float          # 推理耗时
    soft_mask: np.ndarray[6]     # 路由权重
    route_idx: int               # 权重最大的格索引
    is_safe: bool                # 安全标志
    convergence_diff: float      # 收敛判据
    dag_nodes: List[Dict]        # DAG 执行轨迹（来自 C 引擎 trace）
    z_q: np.ndarray[d]          # 融合后的瓶颈向量
```

### 存储策略

两层：

1. **原始环形缓冲区**（raw, 容量 1000 条）：保留最近推理轨迹，用于因果主体的短期因果图构建和反射回路的最新数据分析。固定大小，无动态分配。

2. **下采样长期存储**（long-term, 容量 10000 条）：每 N 步从原始缓冲区抽取一条写入长期存储。采样策略：均匀间隔 + 异常事件过采样（冲突、安全中断、新奇路由模式加权 ×3）。

### 不记录的内容

- 不记录输入 token 序列（体积大，且推理引擎不直接使用原始文本）
- 不记录码本内部状态（只记录输出向量 `z_q`）
- 不记录安全子系统的内部计算（只记录最终的安全标志）

## 三、叙事记忆：从经验中提炼故事

### 触发条件

叙事记忆从黑匣子读取轨迹，按照以下标准筛选"值得记住"的事件：

1. **高预测误差**：预测缓存偏差 `||z_pred - z_actual||²` 超过阈值（动态阈值 = 均值 + 2σ）
2. **安全冲突**：`is_safe == false` 的事件
3. **路由新奇性**：路由权重分布与历史模式 KL 散度 > 阈值
4. **收敛异常**：`convergence_diff` 偏离正常范围（正常范围从历史统计得出）
5. **低概率采样**：随机保留 1% 的普通事件（用于对照基线）

### 记忆表示

```python
@dataclass
class NarrativeRecord:
    step: int
    z_q: np.ndarray[d]         # 关键帧的瓶颈向量
    importance: float           # 重要性分数（由触发条件加权）
    context: Dict               # 触发前后的轨迹切片 (window=5)
    timestamp: float            # 系统时间
    access_count: int           # 后续被访问次数（用于遗忘）
```

### 遗忘机制

- 基于**重要性 × 访问频率**的排序保留
- 容量上限 10000 条，超出时移除最低分记录
- 长期未被访问（超过 5000 步）且重要性低于阈值的记录自动降级删除

### 与系统的关系

- 叙事记忆**不输入**到推理引擎（推理引擎是零参数的纯函数）
- 叙事记忆**输入**到反射回路，作为长期模式分析的素材
- 叙事记忆**输入**到因果主体的边界扩展模块

## 四、反射回路：慢速模式发现

### 运行时机

每 `REFLECT_INTERVAL = 200` 步触发一次。异步执行，不阻塞推理循环。

### 分析内容

1. **路由模式分析**：统计过去 200 步中各路由权重分布，检测是否有格被持续低权重（"废弃格"检测）。如果有格低于 0.05 平均权重超过 1000 步，发出告警。

2. **认知策略稳定性**：计算路由熵的滚动方差。方差过大表示策略不稳定，可能表明输入分布发生变化或模型尚未收敛。

3. **异常检测**：对比近期轨迹与叙事记忆中的历史模式，标记偏离超过 3σ 的状态。

4. **预测缓存命中率趋势**：如果缓存命中率连续下降，发出告警。

### 输出

- 告警（写入日志，不中断推理）
- **策略建议**（写入建议队列，供行为探索器参考）
- 统计报告（可通过 `--obs` 标志在交互式会话中查看）

## 五、因果主体：从序列到因果

### 核心功能

因果主体（`causal_subject.py`）构建并维护一个**因果图**，追踪行动与效果之间的可统计关系。

### 因果图结构

```
节点: StepRecord (黑匣子记录)
有向边: step_i → step_j (i < j)
  权重: 效果显著度 (z_diff 归一化到 [0, 1])

内部边: 自生成 token 之间的推理步骤 (source=1)
外部边: 用户输入触发的步骤 (source=0 → source=1)

计数器:
  n_internal: 内部边数量
  n_external: 外部边数量
  n_total: 总边数
```

### 主体感（Agency）

主体感量化系统对自身行为的控制感知：

```
agency = n_internal / max(n_total, 1)
```

- 范围 [0, 1]
- 初始 baseline = 0（纯反应式）
- 随着系统生成更多 token，agency 逐渐上升
- 突然下降可能表示系统遇到了意外输入或推理失败

### 调制输出

因果主体输出两个调制器，影响推理引擎的行为：

| 调制器 | 来源 | 范围 | 效果 |
|--------|------|------|------|
| `tension` | agency 下降率 + 冲突频率 | [-0.5, 0.5] | 高 → 放松收敛容差（允许更深推理）；低 → 收紧（快速决策） |
| `explore` | 预测误差 + 路由熵 | [-0.3, 0.3] | 高 → 允许更多推理步数（探索）；低 → 减少步数（保守） |

### 反事实推理（Counterfactual）

因果主体支持简单的反事实查询：

- **"如果我没做 X，会怎样？"**：从因果图中移除特定边，重新计算后续轨迹的统计
- 实现方式：从最近 N 步记录中，移除 source=1 的边，比较实际机构与反事实机构
- 差异大 → 表示该步骤对后续结果有显著影响
- 差异小 → 表示该步骤冗余，可考虑跳过

### 边界扩展（Boundary Extension）

当因果主体检测到持续高预测误差（连续 10 步），它触发边界扩展：

1. 标记当前状态为"未知区域"
2. 增加行为探索器的探索概率（p_explore += 0.05，上限 0.5）
3. 降低推理收敛容差（允许更多步骤探索未知空间）
4. 记录边界扩展事件到叙事记忆

## 六、自我格（Self Lattice）

### 设计目的

自我格是一个特殊的格，它不存储外部知识——它存储**系统自身的历史状态原型**。这使得系统能够快速识别"我现在处于什么状态"。

### 结构

- 码本大小：`M_self = 64`
- 维度：`d`（与瓶颈向量一致）
- 更新方式：EMA（`γ_self = 0.99`）
- 初始值：从训练初期 encoder 输出的瓶颈向量采样

### 前向

```
z_self = nearest_neighbor(z, C_self)  # 欧氏距离, STE 梯度
self_bias = α_self × cosine_sim(z, z_self)  # [0, α_self]
```

### 在融合中的作用

自我格输出的 `self_bias` 作为融合阶段的偏置项：

```
z_fused = Σ_i (w_i × z_i) + self_bias × z_self
```

- 当系统处于熟悉状态（高 self_bias）时，自我格贡献更大
- 当系统处于陌生状态（低 self_bias）时，自我格基本不贡献

这创造了一种**熟悉度调制**：系统在熟悉的认知路径上更自信，在陌生领域更依赖外部检索。

## 七、行为探索：自我调制

（此章内容对应原 e.md 第六章，保留但精简标题以匹配新主题）

行为探索器（`behavior_explorer.py`）通过随机扰动路由偏置，观察对内部张力的影响，自发学习哪些偏置能有效降低张力。详见原文档 §六，此处总结关键设计：

- **行为空间**：6 维路由偏置 × 每维 3 个离散值 = 18 个独立参数
- **内部张力**：U = (T_pred + T_conf + T_res) / 3（预测误差 + 价值冲突 + 路由熵）
- **学习**：每维独立 ε-greedy，滑动平均收益
- **安全约束**：危险格检测优先于偏置探索

## 八、自我意识的层次模型

完整的自我意识架构可以视为一个三层控制系统：

```
Level 2 (慢速, 元认知)
  ┌─────────────────────────────────────────────┐
  │ 反射回路    叙事记忆    内在动机反思          │
  │ 模式发现    长期记忆    价值重估              │
  └─────────────────────────────────────────────┘
                      ▲ 统计数据 ▼ 参数建议
                      │
Level 1 (中速, 认知调制)
  ┌─────────────────────────────────────────────┐
  │ 因果主体    行为探索器    自我格              │
  │ 因果追踪    参数扰动    熟悉度检测            │
  └─────────────────────────────────────────────┘
                      ▲ 事件流   ▼ 调制信号
                      │
Level 0 (快速, 认知执行)
  ┌─────────────────────────────────────────────┐
  │ 推理引擎    黑匣子     预测缓存              │
  │ 零参数 DAG  轨迹记录    (z,sig) 复用         │
  └─────────────────────────────────────────────┘
```

- **Level 0**：实时推理 + 原始记录。零参数，无状态，纯函数。
- **Level 1**：基于近期历史（~200 步）的实时调制。有状态，轻量。
- **Level 2**：基于长期历史（~10000 步）的离线分析。异步，重量。

每层只能读取更低层的输出，不能反向干涉。Level 2 的建议必须经过 Level 1 的"安全过滤"才能到达 Level 0。这防止了元认知层直接操控推理引擎。

## 九、当前限制

1. **因果图是统计的，不是结构的**：因果主体检测相关性但不建立结构因果模型。它不知道"为什么"，只知道"当 X 发生，Y 倾向于发生"。

2. **无层次化目标**：系统没有内在的目标层级。行为探索器学习"什么偏置降低张力"，但不问"是否应该降低张力"。目标是一个外部常数。

3. **自观测不参与训练**：黑匣子、叙事记忆、反射回路的数据不用于梯度计算。这些模块是推理时的附加组件，训练时影响有限。

4. **缺乏语言报告能力**：系统不能口头报告"我现在处于什么状态"或"我刚刚学到了什么"。自我意识的表达局限在数值调制信号（tension、explore、self_bias）。

5. **分离而非集成**：各自我意识模块是独立实现的，没有统一的自我表示。一个真正的自我模型需要将因果图、叙事记忆、自我格、偏置历史整合为一个连贯的状态向量。

## 十、未来方向

1. **统一自我状态向量**：将 agency、self_bias、近期张力、路由熵编码为一个固定维度的"自我状态"，作为推理引擎的可选输入。

2. **结构化因果发现**：用简单的干预测试（固定某些路由权重，观察输出变化）替代纯统计相关。

3. **元认知训练**：在少数训练步骤中，让系统学习使用自己的自我状态信号来改进推理质量（例如，调整收敛容差以减少平均推理步数）。

4. **内部语言**：让系统通过标准推理通道（encoder → cognitive loop → W_out）输出自我状态的自然语言描述，而不改变推理引擎本身。

5. **好奇心的梯度化**：将预测误差作为可微分的辅助损失信号，允许内在动机直接影响编码器和码本训练。
