# LCM 因果对话专项实验 V3

日期：2026-09-08

## 目标与通道定义

验证 LCM 主动通道能否在训练期接受 Qwen2.5-0.5B 的语言反馈，并在最终推理时完全移除 Qwen。被动通道仍定义为可读取的诚实内部状态；本实验不把被动文本伪装成模型已知的思考。

## 实现

- 冻结 Qwen，仅预计算局部词表上的软目标。
- 梯度只更新 LCM 编码器、六类认知格和主动生成头。
- 认知循环输出增加编码状态残差，防止不同提示收敛成同一表示。
- 主动头每个时间步持续接收认知状态，并训练 EOS。
- 最终 `student.pkl` 不含任何 Qwen 参数；推理脚本不会加载 Qwen。
- 本轮为 CPU 可行性实验，使用 64 维学生和实验语料局部词表，不代表完整 151936 词表模型。

## 数据与步数

- 基础因果问答：20 对。
- 同义改写增强：20 对，共 40 条训练输入。
- 第一轮路径误用结果作废。
- 正确 answer-only + EOS：500 步。
- 同义增强专项训练：从头 800 步。

## 结果

800 步时监督 CE 从 5.807 降至 0.029，首词因果 margin 降至 0。40/40 训练问法能够输出完整、对应且停止正常的因果回答。

第三套未见改写测试中，人工检查约 11/20 保持正确主题或因果方向；其余出现错误主题映射、短语混合或重复。因此当前结果证明了：主动通道可以在剥离 Qwen 后生成连续中文因果回答，并能有限泛化到改写；但尚未达到开放域正常对话。

Qwen 蒸馏损失在训练后期仍约 9.21，和监督 CE 的下降方向不同，说明当前局部词表上的 Qwen 软目标设计效果不佳。成功主要由因果监督与认知残差带来，不能宣称 Qwen 蒸馏已经有效。

## 下一阶段

1. 将局部词表实验迁移到完整 tokenizer 输出或分层/自适应 softmax。
2. 增加至少数千条多轮因果对话、同义改写和难负样本，并严格划分 train/dev/test。
3. 用相似问题的错误答案做对比损失，直接抑制主题错配。
4. 加入 scheduled sampling / free-running loss，继续减少重复和暴露偏差。
5. 重新设计 Qwen 反馈：对齐隐藏状态或 top-k logits，并单独做有无教师的消融实验。

## 结论

V3 已达到“小域、可剥离教师的因果对话原型”，不是通用对话模型。最终推理确实只使用学生主动通道；Qwen 不在权重中，也不在推理路径中。
