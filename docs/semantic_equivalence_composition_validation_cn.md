# LCM 语言命题 3、4 受控验证报告

日期：2026-09-10  
实验脚本：`train/semantic_composition_propositions.py`  
权重目录：`checkpoints/semantic_composition/`

## 1. 结论

在本报告定义的有限、受控语义域内，命题 3 与命题 4 均通过预注册式阈值。三组随机种子结果完全一致。

- 命题 3：同一概念的训练外表述组合被路由到同一离散概念格；路由准确率与释义路由一致率均为 100%，且没有概念塌缩。
- 命题 4：模型对训练中未出现的 36 个主语—关系—宾语组合实现 100% 自回归整句生成；认知状态打乱与单分量交换对照证明结果依赖因子化状态，而不是仅靠输出先验。

这是一项“小规模存在性证明”，不是开放域自然语言能力证明。它说明当前 LCM 实现能够承载语义等价类和有限因子组合，但尚不能证明其能自动理解未知词、递归句法或开放世界知识。

## 2. 命题和可证伪条件

### 命题 3：语义等价类形成

设路由函数为 \(R\)，属于同一概念的不同表述为 \(x_i\sim x_j\)。要验证：

\[
x_i\sim x_j\Longrightarrow R(x_i)=R(x_j).
\]

通过条件：保留表述的概念格路由准确率与组内一致率均不低于 95%，并且唯一认知状态数不少于应有概念数的 95%。后一个条件防止“所有输入都进同一格”造成虚假一致。

### 命题 4：组合闭包

认知状态被显式分解为：

\[
z(s,r,o)=z_s(s)+z_r(r)+z_o(o).
\]

训练仅覆盖部分三元组，测试集合中的完整三元组从未参与训练。要验证有限原子概念能否形成训练外组合，并要求：

1. 未见组合的自由自回归整句准确率不低于 90%；
2. 打乱认知状态使准确率至少下降 70 个百分点；
3. 单独替换 \(z_s,z_r,z_o\) 时，输出仅按预期改变对应语义成分，准确率均不低于 90%；
4. 三种随机种子的整句准确率标准差不高于 5%。

## 3. 数据与训练设置

语义空间含 6 个主语原子、5 个关系原子和 6 个宾语原子，共 180 个可能三元组。按固定且可复现的规则划分：144 个训练组合、36 个保留组合。

每个原子有两个词汇表面形式。输入的每个语义槽还带包装词和修饰词，因此一个槽由“同义词、包装、修饰”三项构成。训练表述模式为 `(0,0,0)`、`(1,1,1)`、`(0,2,2)`；测试使用三种训练中没有出现过的交叉组合模式。这样，测试既保留完整语义组合，也保留精确表面序列。

每个输入槽先经过共享表面嵌入，再分别读取主语、关系、宾语硬晶格。三个读取值相加为认知状态，学生解码器仅从该状态自回归生成规范化四 token 输出（主语、关系、宾语、EOS）。训练使用标签路由损失、最高 40% 历史 token 扰动和错误状态排序项，降低教师强制捷径。

共训练 3 个独立随机种子（7、17、27），每个 2500 步。保存的是纯学生参数；推理不需要 Qwen。

## 5. 为什么这些对照是必要的

仅有生成准确率不能区分真正组合与查表捷径。这里用了三类互补证据：

- 保留完整三元组：排除直接记忆测试答案。
- 保留精确表面序列并检查同义表述路由：检验语义等价类，而非字符串一致。
- 状态打乱及单分量交换：前者证明生成依赖当前认知状态；后者证明状态中的三个因子具有可干预、可预测的语义绑定。

唯一状态计数同时排除了“全部释义一致是因为全部塌缩到同一格”的退化解。

## 6. 证明边界

本实验支持以下严格表述：

> 对一个有限的三因子语义系统，在原子词汇均于训练中出现、但精确表述和部分完整组合被保留的条件下，当前 LCM 学生架构能够学习表述不变的离散路由，并组合这些状态生成未见三元组。

它没有证明：

- 对训练词表之外的新同义词自然泛化；
- 递归、否定、指代、时序或多跳推理的组合闭包；
- 噪声自然语料中的自动概念发现；
- 开放域对话或长期持续学习稳定性。

下一项应验证命题 5：在深度至少为 2 的递归表达式上，使用长度外推和结构反事实测试，区分真正递归计算与固定模板拟合。

## 7. 复现

在项目根目录运行：

```bash
python -m train.semantic_composition_propositions \
  --steps 2500 \
  --seeds 7,17,27 \
  --output checkpoints/semantic_composition
```

汇总结果写入 `checkpoints/semantic_composition/summary.json`；每个种子的 `student.pkl` 为相应学生权重，`evaluation.json` 为独立评估结果。
