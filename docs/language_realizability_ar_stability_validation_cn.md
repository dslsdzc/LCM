# LCM 语言命题 1–2 联合验证报告

## 目标

本实验不直接声称 LCM 已经完成开放域对话，而是证明两个可组合的局部命题：

1. **语言可实现性**：存在共享语言映射 (G)，能把晶格认知状态展开成多种连续语言表达，并在未见概念组合上保持语义。
2. **自回归闭环稳定性**：训练时成立的状态—语言映射在模型自由生成自身前缀时仍成立，且局部前缀错误不会使后续语义脱离认知状态。

## 数学表述

设离散认知状态为 (z_{a,c})，其中 (a) 为原因概念、(c) 为结果概念；语言风格控制为 (s)，生成器为：

\[
y_t = G(z_{a,c}, s, y_{<t}).
\]

命题 1 要求：

\[
\forall(a,c)\in\mathcal T_{test},\ \forall s\in\{0,1,2\},
\quad \operatorname{Sem}(G(z_{a,c},s))=(a,c),
\]

并且同一 (z) 在不同 (s) 下产生不同表面序列。

命题 2 要求自由前缀与教师前缀的性能接近：

\[
\operatorname{Acc}_{free}\approx\operatorname{Acc}_{TF},
\]

以及对单步前缀扰动 (delta_t)，后续输出仍受 (z) 约束：

\[
\operatorname{Sem}(G(z,s,y_{<t}+\delta_t)_{>t})
\approx \operatorname{Sem}(G(z,s,y_{<t})_{>t}).
\]

## 数据和模型

- 原因原子：8 个，包括火焰、降温、降雨、缺水、通电、撞击、运动和复习。
- 结果原子：6 个，包括温度升高、液体结冰、地面湿润、植物萎蔫、灯具发光和物体破裂。
- 总组合：48；训练 38 个组合，测试 10 个从未训练的组合。
- 每个组合具有三种语言表面形式，测试共 30 条序列。
- 每条序列长度为 6 个受控语言 token，包含原因、结果、连接结构与 EOS。
- 三个独立随机种子：7、17、27。
- 每个认知模型训练 2,500 步；每个 head-only 对照同样训练 2,500 步。
- 认知状态通过两个硬晶格单元组合；生成器不接收问题或概念编号。
- 后半程最高使用 50% 前缀扰动训练。

三种表面形式示例：

- “因为 火焰，所以 温度升高，这一结果。”
- “当 火焰 之后，温度升高，这一结果。”
- “火焰 会导致 温度升高，因而产生这一结果。”

## 命题 1：语言可实现性结果

| 指标 | 认知模型 | Head-only |
|---|---:|---:|
| 未见组合自由生成整句准确率 | **100%** | 0% |
| 自由生成语义准确率 | **100%** | 约 15% |
| 测试集唯一完整序列 | **30/30** | 3/30 |
| 原因晶格路由准确率 | **100%** | 不适用 |
| 结果晶格路由准确率 | **100%** | 不适用 |

三种子所有指标一致，标准差为 0。

这同时证明：

1. 同一认知状态可以由共享生成头实现三种不同表面表达。
2. 不同认知状态产生可区分的原因—结果内容。
3. 训练只覆盖 38/48 组合，剩余 10 个组合仍全部生成正确。
4. 相同语言头在没有认知状态时只能生成三种模板先验，无法完成任何完整语义序列。

因此命题 1 在本实验域内通过。

## 命题 2：自回归闭环稳定性结果

| 指标 | 结果 |
|---|---:|
| Teacher-forced token accuracy | 100% |
| 自由生成 token accuracy | 100% |
| 自由生成整句准确率 | 100% |
| Teacher forcing → free gap | **0** |
| 单 token 扰动后的后缀恢复率 | **100%** |
| 严格错配状态后的语义改变率 | **100%** |
| 三种子自由生成标准差 | 0 |

前缀扰动实验在生成原因 token 后，强制把反馈给下一步的 token 改成错误 token；统计之后四个位置。模型仍全部恢复正确结果、结构和 EOS，说明认知状态在每一步持续进入生成动力学，而不是只初始化第一个 token。

严格状态错配为每个样本选择原因和结果均不同的供体 (z_q)。两个语义位置均随供体状态变化，改变率 100%。这排除了“后续 token 完全依靠语言前缀滚动”的解释。

因此命题 2 在本实验域内通过。

## 通过判据

| 判据 | 阈值 | 结果 |
|---|---:|---:|
| 未见组合整句准确率 | ≥90% | 100% |
| 不同表面序列覆盖 | ≥90% | 100% |
| 认知模型语义准确且 head-only 整句失败 | ≥90% / ≤10% | 100% / 0% |
| TF/free token gap | ≤5% | 0 |
| 前缀扰动后缀恢复 | ≥90% | 100% |
| 错配状态语义改变 | ≥70% | 100% |
| 三种子标准差 | ≤5% | 0 |

七项全部通过：`proposition1_pass=true`、`proposition2_pass=true`、`complete_pass=true`。

## 通向开放域的推导位置

本实验建立了以下局部蕴含：

\[
\text{有限原子概念}
+\text{晶格组合}
+\text{共享语言实现}
+\text{稳定自回归}
\Longrightarrow
\text{未枚举组合的连续语言输出}.
\]

它消除了两处关键断点：新组合不需要在语言头中逐句存储；自由生成不会自动切断认知状态的语义控制。

但从这里到开放域仍需另外证明语义等价类、递归长度外推和开放世界扩展。当前实验使用有限词面和三种语法模板，不等于自然中文开放域已经完成。
